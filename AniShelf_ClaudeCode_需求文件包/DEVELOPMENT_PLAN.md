# AniShelf V1.0 分阶段开发计划

## 总体规则

每个阶段必须先检查当前代码，再实施；每个阶段结束都要运行相应检查并汇报。不得一次性生成大量未经验证的代码。

## 阶段 0：环境检查

目标：确认 Windows 本机具备 Tauri 2 开发条件。

检查：
- Windows 版本与架构；
- Git；
- Node.js LTS、npm、pnpm；
- Rust stable、Cargo；
- Visual Studio C++ Build Tools（MSVC、Windows SDK）；
- WebView2 Runtime；
- 磁盘空间与网络可用性。

缺少组件时：
- 给出官方安装来源；
- 解释用途和是否需要管理员权限；
- 等用户确认后再安装；
- 不擅自修改系统环境变量。

验收：工具版本可读取，Tauri 官方 prerequisites 检查通过。

## 阶段 1：项目骨架与基础 UI

任务：
- 初始化 Tauri 2 + React + TypeScript + Vite；
- 配置 Tailwind CSS、shadcn/ui；
- 配置 ESLint、Prettier、TypeScript strict；
- 建立 feature-based 目录；
- 实现主窗口、侧边栏、标题栏区域、主题；
- 建立路由和基础布局；
- 添加基础错误边界与通知组件。

验收：
- `pnpm install` 成功；
- 前端 typecheck/lint/build 成功；
- `pnpm tauri dev` 可启动；
- 深色主题可见，路由可切换。

## 阶段 2：SQLite 与数据访问层

任务：
- 设计 ER 图和数据字典；
- 建立 SQLite 连接；
- 配置 foreign_keys、WAL、busy_timeout；
- 实现 migration runner；
- 建立 repository/service 基础层；
- 建立核心表及索引；
- 为 FTS 建立同步策略；
- 写 migration 和 repository 测试。

验收：
- 空数据库能完成全部 migration；
- migration 重复启动不重复破坏数据；
- 外键约束生效；
- FTS 的新增、更新、删除同步测试通过；
- 数据库升级前备份流程有效。

## 阶段 3：番剧管理与 Bangumi

任务：
- 番剧列表、详情、添加/编辑；
- 观看状态、评分、标签、评论；
- 集数管理和观看记录；
- Bangumi 搜索、导入、刷新；
- 同步冲突策略；
- 关联笔记入口预留。

验收：
- 断网时手动管理可用；
- 可搜索并导入 Bangumi 作品；
- 标记单集已看后记录正确；
- 同步不会覆盖用户个人数据。

## 阶段 4：书籍资料库与导入

任务：
- 文件选择器；
- EPUB/PDF/TXT/Markdown 类型识别；
- 书籍元数据管理；
- 封面缓存；
- 重复导入检测；
- 文件丢失与重新定位；
- 原始文件只读策略；
- 导入安全校验。

验收：
- 四种格式都能导入为书籍记录；
- 非法/损坏文件能显示错误；
- 不会写入或覆盖原始文件；
- 不自动扫描整个磁盘。

## 阶段 5：阅读器

拆成四个子阶段：
- 5A EPUB：打开、目录、翻页/滚动、进度、书签；
- 5B PDF：打开、页码、缩放、进度、书签；
- 5C TXT：编码检测、分块读取、大文件渲染、进度；
- 5D Markdown：预览、编辑、保存、未保存提示。

统一实现：
- Reader Adapter；
- 阅读设置；
- 自动保存进度；
- 重启恢复位置；
- 阅读会话记录；
- 书签/批注接口。

验收：
- 四种格式均能打开；
- 关闭并重启后恢复阅读位置；
- 大 TXT 文件不会一次性全部载入内存；
- 阅读器错误不会导致应用崩溃。

## 阶段 6：笔记与关联

任务：
- 笔记列表、编辑器、预览；
- 标签；
- 双向链接；
- 笔记关联番剧/书籍/批注；
- 反向链接；
- 删除引用保护；
- 笔记搜索。

验收：
- 笔记 CRUD 可用；
- 双向链接可跳转；
- 关联作品可从笔记页打开；
- 删除关联对象时有明确处理策略。

## 阶段 7：搜索、收藏、统计与首页

任务：
- 全局搜索；
- 收藏；
- Dashboard 汇总；
- 观看/阅读统计；
- 活动时间线；
- 筛选、排序和分页。

验收：
- 搜索覆盖番剧、书籍、笔记；
- 中文搜索方案通过测试；
- Dashboard 数据来自真实数据库；
- 空数据状态展示合理。

## 阶段 8：备份、稳定性与发布

任务：
- 备份/恢复；
- 数据库升级备份；
- 日志与错误反馈；
- 权限和文件路径审计；
- Windows 安装包；
- 图标、版本号、应用元信息；
- 发布前回归测试。

验收：
- 备份可恢复；
- 恢复前自动备份当前数据；
- Windows 构建成功；
- 核心验收场景通过；
- 安装包可在干净 Windows 环境启动。
