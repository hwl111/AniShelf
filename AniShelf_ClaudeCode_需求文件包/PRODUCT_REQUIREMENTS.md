# AniShelf V1.0 产品需求文档（PRD）

## 1. 产品定位

AniShelf 是面向个人用户的 Windows 桌面应用，整合：
1. 番剧收藏与观看管理；
2. 本地电子书阅读；
3. 个人知识笔记与作品关联。

产品采用本地优先策略。用户可以手动管理数据；联网时可通过 Bangumi API 补充番剧元数据。AI 不属于 V1.0 的必要依赖，后续版本再评估接入。

## 2. 目标用户与核心价值

目标用户希望在一个桌面应用中管理自己看过的番剧、正在阅读的书籍，以及从作品中沉淀的笔记和想法。

核心价值：
- 作品资料集中管理；
- 阅读进度和观看进度可追踪；
- 笔记可以关联具体作品、书籍、章节或批注；
- 本地数据可备份、可迁移；
- 不依赖单一在线服务。

## 3. 平台与偏好

- 首发平台：Windows 10/11 64-bit。
- 界面：Dark 深色主题为默认主题。
- 语言：V1.0 至少支持简体中文界面。
- 数据存储：本地 SQLite。
- 书籍格式：EPUB、PDF、TXT、Markdown。
- 番剧数据来源：手动录入 + Bangumi API。
- AI：V1.0 不接入，架构预留扩展点即可。

## 4. 信息架构

主导航建议：
- 首页 Dashboard
- 番剧 Anime
- 书架 Bookshelf
- 阅读器 Reader
- 笔记 Notes
- 搜索 Search
- 设置 Settings

## 5. 功能需求

### 5.1 首页 Dashboard

展示：
- 正在追番的作品；
- 最近观看记录；
- 最近阅读书籍；
- 最近编辑的笔记；
- 阅读/观看活动概览；
- 快捷操作：添加番剧、导入书籍、新建笔记。

首页数据必须来自真实数据库，不得使用长期硬编码的演示数据。

### 5.2 番剧管理 Anime

支持：
- 手动创建番剧；
- 通过 Bangumi 搜索并导入元数据；
- 编辑标题、别名、简介、封面、年份、季度、集数等；
- 观看状态：想看、在看、已看、搁置、弃番；
- 评分、个人标签、个人评论；
- 按状态、年份、标签筛选和排序；
- 番剧详情页展示基本信息、集数、观看记录和关联笔记。

集数与观看记录：
- 管理总集数及单集信息；
- 标记单集已看/未看；
- 记录观看时间；
- 支持补录历史观看记录；
- 单集可写感想，并能关联到笔记系统。

Bangumi 同步：
- 用户主动触发搜索/导入/刷新；
- 保存 Bangumi subject ID；
- 对外部字段和个人字段进行明确区分；
- 同步不得覆盖个人评分、观看状态、观看历史、个人标签和笔记；
- API 失败时保留本地数据并展示可理解的错误。

### 5.3 书籍管理 Bookshelf

支持：
- 通过系统文件选择器导入 EPUB/PDF/TXT/Markdown；
- 记录书名、作者、封面、格式、文件大小、导入时间；
- 书籍分类、标签、收藏；
- 书籍详情页展示阅读进度、书签、批注和关联笔记；
- 支持重新定位原始文件或检查文件是否丢失；
- 原始书籍文件默认只读。

导入策略：
- V1.0 默认采用引用原始文件路径的方式；如实现应用内复制，必须让用户明确选择。
- 应用管理的封面、缩略图、附件和数据库放在应用数据目录。
- 对原文件移动/删除导致路径失效的情况提供重新定位功能。

### 5.4 阅读器 Reader

统一阅读器入口，按文件格式选择 Adapter。

EPUB：
- 打开、翻页/滚动；
- 目录导航；
- 字体大小、行距、主题等基础阅读设置；
- 记录章节和阅读位置；
- 书签与批注（能力允许时）。

PDF：
- 页面导航；
- 缩放、适合宽度/页面；
- 记录页码和缩放状态；
- 书签和文本批注能力按 PDF.js 可实现范围交付。

TXT：
- 编码检测，至少处理 UTF-8、UTF-8 BOM、GBK/GB18030 等常见编码；
- 大文件分块读取，不一次性把超大文件全部载入内存；
- 分页或虚拟列表；
- 保存字符偏移/段落位置等可恢复定位信息。

Markdown：
- 阅读预览；
- 编辑模式；
- 保存与未保存状态提示；
- Markdown 文件原文不得因预览而被改写。

通用：
- 自动保存阅读进度；
- 重新打开时恢复上次位置；
- 阅读设置持久化；
- 书签和批注可关联笔记。

### 5.5 笔记 Notes

支持：
- 新建、编辑、删除笔记；
- Markdown 编辑与预览；
- 标签；
- 双向链接；
- 关联番剧、书籍、章节、批注；
- 反向链接面板；
- 按更新时间、创建时间排序；
- 全文搜索。

删除笔记时，对被其他笔记引用的情况给出提示；删除行为不得静默破坏引用关系。

### 5.6 搜索 Search

支持搜索：
- 番剧标题、别名、简介；
- 书名、作者；
- 笔记标题与正文；
- 标签；
- 可搜索的批注内容。

中文搜索必须实测。若 SQLite FTS5 的默认 tokenizer 不满足中文搜索需求，应采用经过验证的 tokenizer、应用层分词或合理的降级搜索方案，并说明性能限制。

### 5.7 设置 Settings

至少包括：
- 主题；
- 数据库/应用数据目录信息；
- 备份与恢复；
- Bangumi API 配置与连接状态；
- 阅读器默认设置；
- 关于页面、版本信息。

### 5.8 备份与恢复

- 支持备份 SQLite 数据库；
- 提醒用户书籍原文件可能位于应用数据目录之外，需要单独备份；
- 备份应包含版本信息和必要元数据；
- 恢复前自动备份当前数据库；
- 恢复失败时不能破坏当前可用数据。

## 6. 非功能需求

- Windows 桌面体验优先；
- 核心功能离线可用；
- 数据库操作有错误处理；
- 大文件阅读避免明显卡死；
- 关键操作提供加载、空状态、错误状态；
- 深色主题对比度可读；
- 应用启动后不应自动扫描整个磁盘；
- 不在未经用户操作时上传书籍、笔记或个人数据。

## 7. V1.0 不做的事情

- AI 自动总结/问答/提示词生成；
- 云端账号与多设备同步；
- 移动端；
- 社区、评论和社交功能；
- 自动下载番剧资源；
- DRM 破解或绕过；
- 自动整理/改写用户原始书籍文件。

## 8. V1.0 验收场景

1. 用户断网时仍可手动添加番剧、导入本地书籍、阅读和写笔记。
2. 用户可从 Bangumi 搜索作品并导入基本资料。
3. 用户标记某集已看后，观看记录和进度正确更新。
4. 用户导入 EPUB/PDF/TXT/Markdown 后能用对应阅读器打开。
5. 关闭并重新打开应用后，阅读进度能够恢复。
6. 用户可以创建笔记并关联番剧或书籍。
7. 用户能通过双向链接看到引用关系。
8. 用户备份后可在测试环境恢复数据。
9. 数据库迁移、前端构建、Rust 检查和核心测试全部通过。
