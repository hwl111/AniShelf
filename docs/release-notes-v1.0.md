# AniShelf V1.0 发布说明

- 版本：1.0.0
- 日期：2026-11-24
- 平台：Windows 10/11 x64

## 1. 概述

AniShelf 是本地优先的桌面知识管理应用，把番剧管理、本地电子书阅读与知识笔记放在同一个应用里。V1.0 的核心数据默认保存在本机，观看记录、阅读、笔记、搜索、收藏与备份无需联网即可使用。

## 2. 主要功能

- **番剧管理**：手动添加、编辑、评分、标签、五种观看状态；集数与观看记录；可选 Bangumi 搜索/导入/刷新，外部元数据与个人数据分离。
- **书架与阅读器**：导入 EPUB/PDF/TXT/Markdown；EPUB 目录、字体/行距/主题、进度与书签；PDF 页码/缩放/进度/书签；TXT 编码检测、分块读取、连续滚动与进度恢复。
- **书籍封面**：EPUB 使用内置封面；PDF 自动使用第 1 页作为封面；TXT 使用正文首页样式生成封面；已有封面不会被覆盖，原文件只读。
- **笔记与关联**：纯文本笔记、标签、笔记间链接与反向链接、关联番剧/书籍/集数；删除前提示引用影响。
- **搜索、收藏与首页**：中文全文搜索（FTS5 trigram + 短词回退）、收藏页、真实数据统计与活动时间线。
- **备份与恢复**：数据库备份、另存为、备份列表；恢复前自动备份当前数据库，恢复在重启后生效，失败保留当前数据。
- **本地与安全**：最小 Tauri 权限、CSP、Zip Slip 防护、外链限制、单实例运行、本地日志。

## 3. 系统要求

- Windows 10/11 x64。
- Microsoft Edge WebView2 Runtime（Windows 11 通常已安装；安装器会在缺失时提示安装）。
- 推荐可用磁盘空间 300MB 以上；书籍文件按实际大小另计。

## 4. 安装与升级

1. 运行 `AniShelf_1.0.0_x64-setup.exe`。
2. 安装为当前用户级应用，不需要管理员权限。
3. 安装包未做代码签名，Windows SmartScreen 可能显示“未知发布者”；请核对文件哈希后再运行。
4. 升级安装会保留应用数据；数据库结构升级前会自动备份到应用 `backups/` 目录。

## 5. 数据位置与备份

- 默认数据目录：`%LOCALAPPDATA%\com.anishelf.desktop`
- 数据库：`database\anishelf.sqlite`
- 封面与生成封面：`covers\`
- 备份：`backups\`
- 日志：`logs\anishelf.log`
- 原始书籍文件默认保留在用户选择的位置，**不会包含在数据库备份中**；迁移或重装前请单独备份这些文件。

## 6. 已知限制

- Markdown 阅读/编辑在 V1.0 中未提供；已导入的 `.md` 书籍保留记录但不可阅读。
- 批注功能未实现，仅提供书签；因此笔记暂不能关联批注。
- PDF 仅画布阅读，不支持文本选取/高亮；PDF 第 1 页封面会在进入书架时按需生成，超大 PDF 首次生成可能较慢。
- TXT 进度为按字节偏移的近似值，恢复时向前对齐到行首；超大文件不会一次性载入内存。
- 搜索每类最多返回 20 条；1–2 字查询使用 LIKE 回退。
- 活动时间线由现有数据实时派生；阅读时长只统计正常结束的阅读会话。
- 安装包未签名；V1.0 不含自动更新。
- Bangumi 访问在中国大陆可能需要网络代理，失败时不影响本地功能。

## 7. 验证结果

- Rust：90 个测试通过，`cargo fmt`、`cargo clippy -D warnings` 通过。
- 前端：`pnpm typecheck`、`lint`、`format:check`、`test`、`build` 通过。
- 安装包：`pnpm tauri build` 成功生成 NSIS 安装包。
- 干净数据目录启动：发布版 exe 使用全新的 `ANISHELF_DATA_DIR` 启动，成功创建空数据库并应用 9 个迁移，无残留数据依赖；日志记录启动版本与 schema 9。
- 安全审计：见 `docs/security-audit.md`。
