# 阶段 6 验收报告（笔记与关联）

- 日期：2026-11-24
- 结论：**通过**

## 范围说明

按用户决定，本阶段范围与需求包原方案有以下差异：

1. **阶段 5D 已取消**：不实现书籍的 Markdown 阅读/编辑；已导入的 `.md` 书籍记录保留，打开时显示「该格式阅读器尚未接入」。
2. **笔记编辑器为纯文本**：不渲染 Markdown，笔记内容沿用 `notes.content_md` 列存储，未新增表结构。
3. **关联对象为番剧、书籍、集数**：现有 `note_relations` 表结构即可满足；「章节」按现有 schema 解释为番剧集数。
4. **批注关联未提供**：5A–5C 只交付了书签，批注功能尚未实现，因此不提供空的批注关联入口，避免伪造能力。
5. **双向链接使用显式选择器**：不解析 `[[标题]]` 语法，避免同名标题歧义。

## 1. 完成内容

1. **笔记 CRUD**：创建、读取、更新、删除；标题与正文至少一项非空；标题最多 300 字符、正文最多 200000 字符；标签最多 20 个、单个最多 50 字符并去重。
2. **标签**：复用 `tags` / `entity_tags`，笔记标签与番剧、书籍标签共享；删除笔记时清理多态标签。
3. **搜索**：笔记列表支持关键词、标签筛选与排序（最近更新/最近创建）；3 个及以上字符使用 FTS5 trigram，1–2 个字符降级为转义 LIKE；正文可搜索；FTS 由现有触发器随增删改同步。
4. **双向链接**：显式选择目标笔记写入 `note_links`；编辑页显示「出链」与「反向链接」；移除链接后双向同步消失；禁止链接到自身；被引用笔记删除时展示引用列表。
5. **实体关联**：笔记可关联番剧、书籍、集数（`note_relations`）；支持按类型搜索候选；Service 层校验目标存在性；重复关联忽略；支持移除。
6. **删除保护**：删除存在反向链接的笔记时，后端在未确认情况下拒绝删除并返回引用信息；前端弹窗列出引用笔记，确认后级联清理链接；删除番剧/书籍/集数时，弹窗显示将受影响的笔记数量。
7. **前端页面**：
   - `/notes` 笔记列表（搜索、标签筛选、排序、加载更多、空/错误状态）
   - `/notes/new`、`/notes/:noteId` 纯文本编辑器（Ctrl+S、未保存标记、离开拦截）
   - 关联选择器、笔记链接选择器、反向链接面板
   - 番剧与书籍详情的「相关笔记」卡片；「新建笔记」保存后自动关联当前作品
8. **路由与入口**：新增笔记路由；侧边栏既有「笔记」入口接入真实页面。
9. **数据兼容**：无新增 migration；沿用 0005/0006/0008 既有表、索引、FTS 触发器。

## 4. 已知事项

1. 笔记为纯文本编辑器，不渲染 Markdown；阶段 5D 的书籍 Markdown 阅读器已取消，`.md` 导入记录保留但不可阅读。
2. 双向链接只能通过选择器建立，不支持在正文中输入 `[[标题]]`。
3. 批注功能尚未实现，笔记暂不能关联批注；数据库结构已预留。
4. 书籍章节关联未实现；当前「章节」以番剧集数承载。
5. 删除笔记会永久移除其出链与关联；删除前会列出反向链接并要求确认。删除番剧/书籍/集数时只显示受影响笔记数量，不列出全部标题。
6. 笔记不会自动保存；未保存修改通过 Ctrl+S 或保存按钮写入。
7. 笔记列表一次最多加载 200 篇；更多内容需通过搜索或标签筛选缩小范围（阶段 7 会补充全局搜索与分页）。
8. 主 JS 包体积警告仍在（约 1.44MB）；路由级拆包留到阶段 7/8。
