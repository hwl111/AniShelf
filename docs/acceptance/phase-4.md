## 1. 完成内容

1. **文件选择与导入**：
   - Tauri dialog 插件系统文件选择器，仅允许 EPUB/PDF/TXT/Markdown。
   - 扩展名 + 实际内容双重校验：EPUB ZIP/OPF、PDF `%PDF-` 头、文本二进制检测。
   - 1GB 文件上限、空文件/权限/损坏文件可读错误；整个导入过程不修改原始文件。
2. **EPUB 解析**：
   - `container.xml` → OPF → `dc:title`、`dc:creator`、`dc:description`、封面。
   - 封面写入 `covers/` 并通过 Tauri asset 协议显示（scope 仅 `$APPLOCALDATA/covers/**/*`）。
   - 归档路径解析拒绝 `..`、绝对路径与 URL，封面写到应用控制的文件名，防 Zip Slip。
3. **去重与复制**：
   - SHA-256 内容哈希 + 规范化路径双重去重；重复导入返回已有书籍并提示。
   - 默认引用原文件；导入对话框可勾选“复制到应用资料库”，副本存 `attachments/books/`，`source_path` 记录原路径（0009 迁移）。
4. **书籍资料库**：
   - 书名/作者/分类/简介/标签/收藏；格式、分类、标签、收藏筛选与排序。
   - 文件丢失检测与重新定位；损坏/缺失文件提示。
   - 删除书籍时清理笔记关联、标签、收藏与阅读数据；仅删除应用管理的封面/副本，**绝不删除原始文件**。
5. **UI**：书架卡片与封面、导入对话框、书籍详情、编辑、收藏、重新定位、删除确认；加载/空/错误状态。

## 4. 已知事项

1. 仅 EPUB 提取封面；PDF/TXT/Markdown 使用占位封面（阅读器阶段可补充 PDF 渲染缩略图）。
2. PDF 元数据只校验文件头，书名默认取文件名；作者/书名可在详情页编辑。
3. TXT/Markdown 编码检测留到阶段 5C；导入阶段只拒绝含 NUL 的二进制文件。
4. 应用内副本若丢失，重新定位会提示重新导入；重新定位仅适用于引用原文件的书籍。
5. 文件选择器返回路径由 Rust 后端重新规范化与校验；前端不具备任意路径读写能力。
6. 测试样本位于 `F:\AniShelf_samples`，生成脚本位于 `F:\AniShelf_tmp`，可手动删除。
7. 临时脚手架目录 `f:\AniShelf_bootstrap_20261124` 仍在，需手动删除。
8. 前端产物约 580 kB，Vite 提示需要拆包；阶段 7/8 优化。
