# 阶段 7 验收报告（搜索、收藏、统计与首页）

- 日期：2026-11-24
- 结论：**通过**

## 1. 完成内容

1. **全局搜索**
   - 搜索结果新增副标题/上下文；批注结果附带所属书籍 ID，可跳转书籍详情。
   - 番剧、书籍、笔记、批注每类最多 20 条，避免单一类型挤占全部结果；关键词长度限制 200 字符。
   - 中文搜索：3 个字符及以上使用 FTS5 trigram，1–2 个字符使用转义 LIKE 回退；保持既有覆盖测试。
   - 搜索页：250ms 防抖、分组展示、类型筛选、空/加载/错误状态、结果跳转与每类限额说明。
2. **收藏**
   - 笔记支持收藏：`Note`/`NoteSummary` 增加 `isFavorite`，新增切换命令；删除笔记时清理收藏记录。
   - 番剧筛选新增 `favorite`，书籍沿用已有收藏筛选。
   - 新增 `/favorites` 收藏页（番剧/书籍/笔记三个标签），支持直接取消收藏；侧边栏新增「收藏」入口。
   - 笔记列表增加收藏筛选与已收藏星标；笔记编辑页增加收藏按钮。
3. **首页 Dashboard（全部真实数据）**
   - 新增 `get_dashboard` 聚合接口：正在追番、最近观看记录、最近阅读、最近编辑笔记、统计与活动时间线。
   - 统计包含：番剧总数/在看/已看/收藏、书籍总数/阅读中/收藏、笔记总数/收藏、已看集数、观看记录数、阅读会话数与阅读时长。
   - 活动时间线由观看记录、阅读进度、笔记更新、书籍导入、番剧添加实时派生，未使用硬编码数据。
   - 首页全部卡片来自数据库；保留加载/错误/空状态；快捷操作「添加番剧」「导入书籍」会跳转并自动打开对话框，「新建笔记」直达新建页。
4. **筛选、排序、分页**
   - 笔记：搜索、标签、收藏筛选、最近更新/创建排序、加载更多（最多 200 篇）。
   - 番剧、书籍：既有筛选与排序保留；番剧新增收藏筛选。
   - 搜索：每类限额 20 条，界面明确说明。

## 4. 已知事项

1. 批注创建功能尚未实现；搜索与收藏对批注只覆盖数据库中已有数据，批注结果只能跳转到所属书籍。
2. 活动时间线为现有数据实时派生，不写入 `activity_logs`；同一书籍可能同时出现「导入书籍」与「阅读进度」两条事件。
3. 阅读时长只统计正常结束的阅读会话；应用被强制退出时未结束的会话不计入。
4. 搜索每类最多 20 条，不做全文分页；1–2 字查询使用 LIKE 扫描，数据量很大时性能低于全文索引。
5. 收藏页笔记最多加载 200 篇，番剧/书籍使用现有列表接口，未做独立分页。
6. 「阅读中的书籍」统计包含已有阅读进度记录的全部书籍（含 100%）。
7. 主 JS 包体积警告仍在（约 1.47MB）；路由级拆包留到阶段 8 评估。
8. 测试样本与临时脚本目录仍在，可手动清理。
