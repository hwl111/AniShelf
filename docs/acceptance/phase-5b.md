# 阶段 5B 验收报告（PDF 阅读器）

- 日期：2026-11-24
- 结论：**通过**

## 1. 完成内容

1. **后端**：`read_book_bytes` 支持 EPUB/PDF（200MB/300MB 上限）；阅读位置新增 `pdf_page`，进度与书签校验通过。
2. **PDF.js**：pdfjs-dist 6.5.438 + 本地 worker、cmaps、standard_fonts、wasm、iccs；ArrayBuffer 经 IPC 加载。
3. **渲染**：单页画布渲染、设备像素比适配、白底；页码变化/缩放/容器尺寸变化时重渲染；取消旧渲染任务避免画布冲突。
4. **导航与缩放**：上一页/下一页、页码输入、键盘翻页（←/→/PageUp/PageDown/Space）；放大/缩小、适合宽度、适合页面；缩放比例显示。
5. **持久化**：保存页码、缩放模式与有效缩放比例、百分比；重开恢复；书签新增/跳转/删除；阅读会话开始/结束。
6. **格式分发**：`/reader/:bookId` 根据格式进入 EPUB、PDF；TXT/Markdown 显示待接入；书籍详情对 EPUB/PDF 均提供阅读入口与进度。
7. **生产 CSP**：PDF.js worker/wasm 在生产构建中可用。

## 4. 已知事项

1. PDF 仅交付画布阅读与书签；文本选取、高亮、批注未实现（按阶段范围，不伪造支持）。
2. 未实现 PDF 大纲/目录；仅页码导航。
3. PDF 全量读入内存（上限 300MB），未使用 Range 分段加载；超大 PDF 仍可能占用较多内存。
4. `pdfjs-dist` 主包与 worker 较大（主 JS 约 1.4MB、worker 约 1.27MB）；路由级拆包留到阶段 7/8。
5. 应用被强制结束时阅读会话可能保持未结束；统计阶段需忽略未结束会话。
6. 三页测试 PDF 由脚本生成（英文文本，避免内置字体缺字）；中文 PDF 的 CMap 资源已本地打包，仍需真实中文 PDF 回归。
7. 测试样本与临时脚本目录仍在，可手动清理。
