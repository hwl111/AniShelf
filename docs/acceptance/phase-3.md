## 4. 已知事项

1. **网络限制**：当前网络将 `api.bgm.tv` 解析到异常地址并超时（DNS 污染/阻断），需 VPN/代理才可访问；Bangumi 在线流程已实现但未做真实联网验收。国内没有合规且稳定的直接替代源（AniList/MAL/TMDB 通常同样不稳定或被阻断；豆瓣无公开 API）。后续可选增强：设置页 HTTP 代理、Bangumi 导出文件导入。
2. Bangumi 封面仅保存外部 URL，尚未下载/缓存到应用数据目录；封面显示在阶段 4 一并处理。
3. Bangumi 的评分与标签属于外部数据，未导入为个人评分/个人标签（符合数据边界要求）。
4. 单集感想已保存在观看记录中；与笔记系统的关联 UI 在阶段 6 实现（数据库/清理逻辑已就绪）。
5. 活动日志尚未写入；Dashboard 统计在阶段 7。
6. 前端产物约 561 kB，Vite 提示需拆包；路由级懒加载可在阶段 7/8 优化。
7. 前端端到端测试仍以路由冒烟为主，业务正确性由 Rust 服务测试覆盖。
8. 临时脚手架目录 `f:\AniShelf_bootstrap_20261124` 仍在，需手动删除。
