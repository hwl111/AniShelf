- 日期：2026-11-24

## 1. 完成内容

1. **阅读数据层**：
   - `read_book_bytes` 经 Tauri IPC 返回 ArrayBuffer；Rust 校验书籍存在、格式为 EPUB、文件可用、≤200MB。
   - 阅读进度 upsert（CFI + JSON + 百分比），同时更新 `books.last_opened_at`。
   - 书签 CRUD；阅读设置按 scope 持久化；阅读会话开始/结束与时长。
   - 外链命令仅允许 http/https，用户点击后才打开。
2. **EPUB 阅读器**：
   - epub.js 0.3.93，二进制 ArrayBuffer 加载，`allowScriptedContent: false`。
   - 目录面板（嵌套章节）、上一页/下一页、键盘翻页（←/→/PageUp/PageDown/Space）。
   - CFI 位置保存与恢复；800ms 防抖保存；退出时立即刷新进度与结束会话。
   - 字号、行距、深色/浅色/护眼主题，设置自动保存并跨重启恢复。
   - 书签新增/跳转/删除；侧栏显示创建时间。
   - 章节页数与全书百分比；位置索引未就绪时使用 spine/page 估算，生成后校正。
   - 异常 EPUB/缺失文件显示可读错误并可重试，不崩溃。
3. **入口**：书籍详情“阅读/继续阅读”按钮、阅读进度卡片；`/reader/:bookId` 路由。
4. **生产 CSP 验证**：blob/iframe/字体样式在 `tauri build` 产物中正常。

## 4. 已知事项

6. 外链由 Rust 校验 http/https 后调用系统打开；未做真实外链手动测试。
